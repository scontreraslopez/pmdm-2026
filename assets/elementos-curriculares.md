**Actualizados conforme al RD 405/2023**, que reescribe expresamente el módulo **0489 – Programación multimedia y dispositivos móviles**. En la Comunitat Valenciana el módulo está actualmente situado en 2.º de DAM con **133 horas / 4 h semanales**, pero los RA y CE vienen de esta actualización estatal. ([BOE][1])

* **RA1. Aplica tecnologías de desarrollo para dispositivos móviles evaluando sus características y capacidades.** ([BOE][2])

  * **CE1a.** Se han analizado las limitaciones que plantea la ejecución de aplicaciones en los dispositivos móviles.
  * **CE1b.** Se han identificado las tecnologías de desarrollo de aplicaciones para dispositivos móviles.
  * **CE1c.** Se han instalado, configurado y utilizado entornos de trabajo para el desarrollo de aplicaciones para dispositivos móviles.
  * **CE1d.** Se han identificado configuraciones que clasifican los dispositivos móviles en base a sus características.
  * **CE1e.** Se han descrito perfiles que establecen la relación entre el dispositivo y la aplicación.
  * **CE1f.** Se ha analizado la estructura de aplicaciones existentes para dispositivos móviles identificando las clases utilizadas.
  * **CE1g.** Se han realizado modificaciones sobre aplicaciones existentes.
  * **CE1h.** Se han utilizado emuladores para comprobar el funcionamiento de las aplicaciones.

* **RA2. Desarrolla aplicaciones para dispositivos móviles analizando y empleando las tecnologías y librerías específicas.** ([BOE][2])

  * **CE2a.** Se ha generado la estructura de clases necesaria para la aplicación.
  * **CE2b.** Se han analizado y utilizado las clases que modelan ventanas, menús, alertas y controles para el desarrollo de aplicaciones gráficas sencillas.
  * **CE2c.** Se han utilizado las clases necesarias para la conexión y comunicación con dispositivos inalámbricos.
  * **CE2d.** Se han desarrollado aplicaciones que hacen uso de las funcionalidades proporcionadas por los sensores.
  * **CE2e.** Se han utilizado las clases necesarias para establecer conexiones y comunicaciones HTTP y HTTPS.
  * **CE2f.** Se han utilizado las clases necesarias para establecer conexiones con almacenes de datos garantizando la persistencia.
  * **CE2g.** Se han realizado pruebas de interacción usuario-aplicación para optimizar las aplicaciones desarrolladas a partir de emuladores.
  * **CE2h.** Se han empaquetado y desplegado las aplicaciones desarrolladas en dispositivos móviles reales.
  * **CE2i.** Se han documentado los procesos necesarios para el desarrollo de las aplicaciones.
  * **CE2j.** Se han establecido los permisos requeridos para el funcionamiento de las aplicaciones.

* **RA3. Desarrolla programas que integran contenidos multimedia analizando y empleando las tecnologías y librerías específicas.** ([BOE][2])

  * **CE3a.** Se han analizado entornos de desarrollo multimedia.
  * **CE3b.** Se han reconocido las clases que permiten la captura, procesamiento y almacenamiento de datos multimedia.
  * **CE3c.** Se han utilizado clases para la conversión de datos multimedia de un formato a otro.
  * **CE3d.** Se han utilizado clases para procesar datos multimedia.
  * **CE3e.** Se han utilizado clases para el control de eventos, tipos de media y excepciones, entre otros.
  * **CE3f.** Se han utilizado clases para la creación y control de animaciones.
  * **CE3g.** Se han utilizado clases para reproducir contenidos multimedia.
  * **CE3h.** Se han depurado y documentado los programas desarrollados.

* **RA4. Selecciona y prueba motores de juegos analizando la arquitectura de juegos 2D y 3D.** ([BOE][2])

  * **CE4a.** Se han identificado los elementos que componen la arquitectura de un juego 2D y 3D.
  * **CE4b.** Se han analizado los componentes de un motor de juegos.
  * **CE4c.** Se han analizado entornos de desarrollo de juegos.
  * **CE4d.** Se han analizado diferentes motores de juegos, sus características y funcionalidades.
  * **CE4e.** Se han identificado los bloques funcionales de un juego existente.
  * **CE4f.** Se ha reconocido la representación lógica y espacial de una escena gráfica sobre un juego existente.

* **RA5. Desarrolla juegos 2D y 3D sencillos utilizando motores de juegos.** ([BOE][2])

  * **CE5a.** Se ha establecido la lógica de un nuevo juego.
  * **CE5b.** Se han creado los objetos necesarios para el juego y definido sus características.
  * **CE5c.** Se han creado las escenas del juego y distribuido los objetos en las mismas.
  * **CE5d.** Se han creado materiales para determinar las propiedades finales de la superficie de un objeto.
  * **CE5e.** Se han establecido las propiedades físicas de los objetos.
  * **CE5f.** Se ha incorporado sonido a los diferentes eventos del juego.
  * **CE5g.** Se han utilizado cámaras y configurado la iluminación.
  * **CE5h.** Se han desarrollado e implantado juegos para dispositivos móviles.
  * **CE5i.** Se han realizado pruebas de funcionamiento y optimización de los juegos desarrollados.
  * **CE5j.** Se han documentado las fases de diseño y desarrollo de los juegos creados.
